## Upcoming

This section describes planned items that are not released yet. Timing and scope may change.

### Version 1.2.0 (Planned)

- **Flatten feature**: Move all currently sorted items back to the root of the project panel.
- **Improved solids organization**: Stronger handling for consolidating and organizing solids.
- **Rename feature**: Batch edit or replace names and comments for selected project items or composition layers.
- **Shift + Run for folder-only creation**: Build the folder structure without moving assets.

---

## Released Versions

### Version 1.1.0 (February 11, 2026)

- **Premiere Pro support**: Added support for Premiere Pro, including filters for offline files, captions, MOGRTs, multicam, merged clips, and proxies.
- **Selection-based organization**: Added the ability to organize around selected compositions or sequences as separate master folders.
- **Improved debug logging**: Added more detailed diagnostic logs to help identify failures.

---

Official first stable release of Seiton.
