Open the settings screen from the gear icon. This is where you manage cleanup rules, button display, debug logging, and language preferences.

## Options (defaults)

| Option | Default | Description |
|---|:--:|---|
| Delete empty folders | ON | Remove folders that become empty after organization |
| Delete unused solids/nulls | OFF | AE only: remove unused solids and null objects |
| Delete unused media | OFF | AE only: remove media that is not referenced by any comp |
| Button display | Icon + Text | Button display mode |
| Debug logging | OFF | Save execution logs to the desktop |

## Debug logging

When enabled, logs are saved to the desktop for each run (`Seiton_Ae_Log_*.txt` / `Seiton_Pr_Log_*.txt`). Logs stay local and are not sent automatically.
