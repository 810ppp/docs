---
title: Filter Priority
description: Learn how Seiton decides which folder an item is sorted into when multiple filters match.
---

If the same item matches multiple folders, Seiton uses the following order.

1. Deeper folders take priority over parent folders.
2. Within the same level, name-based filters take priority over extension filters, which take priority over media-type filters.

<Example>
  If you have `01_Image` with an image filter and `PSD` with a `.psd` extension filter, a PSD file is sorted into `PSD`.
</Example>
