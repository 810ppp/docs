Common questions about safety, undo behavior, and Premiere Pro limitations.

<AccordionGroup>
  <Accordion title="Q1. Does Seiton change files on disk?">
    No. Seiton works only inside the project.

    - It creates folders, moves items inside the project, and applies labels.
    - It does not delete, move, or rename files on disk.
  </Accordion>

  <Accordion title="Q2. What does Delete Empty Folders remove?">
    It only removes empty folders inside the project panel.

    - After Effects: supported.
    - Premiere Pro: not supported because of API limitations.

    It never deletes folders on disk.
  </Accordion>

  <Accordion title="Q3. Can I undo organization?">
    Yes.

    - After Effects: one Undo is usually enough.
    - Premiere Pro: multiple Undo steps may be required.

    The project is saved automatically before execution.
  </Accordion>

  <Accordion title="Q4. What should I send when reporting a bug?">
    Please include reproduction steps and a debug log.

    See [Help & Support](/en/seiton/support/help).
  </Accordion>
</AccordionGroup>
