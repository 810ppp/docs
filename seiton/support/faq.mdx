安全性、Undo、Premiere Pro の制約について、よくある質問を先にまとめています。

<AccordionGroup>
  <Accordion title="Q1. ディスク上の素材に影響はありますか？">
    いいえ。Seiton はプロジェクト内だけ操作します。

    - フォルダ作成 / 移動 / ラベル付けのみ行います。
    - ディスク上の削除 / 移動 / リネームはしません。
  </Accordion>

  <Accordion title="Q2. 「空のフォルダ削除」は何を消しますか？">
    プロジェクトパネル内の空フォルダのみです。

    - Ae: 空フォルダを整理後に削除します。
    - Pr: API 制限により未対応です。

    ディスク上のフォルダは削除しません。
  </Accordion>

  <Accordion title="Q3. Undo できますか？">
    可能です。

    - Ae: 1 回の Undo で戻せます。
    - Pr: 複数回 Undo が必要になる場合があります。

    整理後に保存せずにプロジェクトを閉じて開き直してください。実行直前に必ず保存される仕様になっています。
  </Accordion>

  <Accordion title="Q4. 不具合があったときは？">
    デバッグログを添えてご連絡ください。状況確認に使います。

    → [ヘルプ・問い合わせ](/seiton/support/help)
  </Accordion>
</AccordionGroup>
